# 交易系统设计文档

> 编写日期：2026-05-22

---

## 一、核心设计理念

**不是预测涨跌，而是只在高概率环境里做高质量交易。**

四层过滤体系：
1. 市场是否适合做多
2. 板块是否在主线
3. 个股是否强于市场
4. 位置和风险是否划算

少一个条件，直接不做。

---

## 二、市场四种状态

| 状态 | 条件 | 仓位 |
|:-----|:-----|:-----|
| **TREND_UP** | 指数收盘价 > 21EMA，EMA斜率向上，Donchian上移，ATR扩张 | 75%-100% |
| **MEAN_REVERSION** | 21EMA走平，Donchian收窄，Keltner上下轨反复触碰 | 25%-50% |
| **COMPRESSION** | 波动率低，ATR收缩，Donchian极窄，方向不明确 | 0%-25% |
| **TREND_DOWN** | 指数跌破21EMA，EMA向下，价格沿下轨运行 | 0% |

---

## 三、入场规则

### 突破型
- 条件：Donchian突破 + 放量 + 市场TREND_UP + 主线板块 + 个股强于板块
- 禁止：追已经连续大涨后的高潮段

### 回踩型（优先级最高）
- 条件：已发生突破 → 回踩21EMA → 缩量 → 不破结构 → 再次转强

---

## 四、止损规则

- 单笔最大亏损：总资金的 1%-2%
- 触发：跌破关键结构 / 跌破ATR止损位 / 放量跌破21EMA / 主线板块转弱
- 原则：一旦触发，机械执行

---

## 五、止盈规则

- 不猜顶
- 分批减仓 + 移动止损
- 趋势没坏就让利润奔跑

---

## 六、仓位规则

- 由市场状态决定，不由情绪决定
- 单票初始仓位：总资金的 10%-20%

---

## 七、证伪机制

| 时间点 | 触发条件 | 动作 |
|:-------|:---------|:-----|
| T+0 收盘 | 跌破入场关键价位 | 次日开盘评估 |
| T+1 动量 | 未量价齐升（成交量 > 前5日均量，且价格未创新高） | 减半仓 |
| T+3 逻辑 | 未触及第一止盈位（+5%） | 强制离场 |

---

## 八、熔断机制

- 连亏 2 笔 → 减仓
- 连亏 4 笔 → 停止交易，重新观察市场
- 市场状态识别失真 → 先降频

---

## 九、评分规则

统一规则（三个评分）：
- 市场分 + 板块分 + 个股分
- 80分以上：可做
- 70-79分：观察
- 70分以下：过滤

---

## 十、通道指标参数

### 凯尔特纳通道 (Keltner Channels)
```
中轨 = EMA(close, 21)
上轨 = EMA(close, 21) + 2 × ATR(14)
下轨 = EMA(close, 21) - 2 × ATR(14)
```

### 薛斯通道 (Xosi Channels)
```
长期通道（外轨）：
  上轨 = MA(high, 60) + 2 × STD(high, 60)
  下轨 = MA(low, 60) - 2 × STD(low, 60)

短期通道（内轨）：
  上轨 = MA(high, 5) + 2 × STD(high, 5)
  下轨 = MA(low, 5) - 2 × STD(low, 5)
```

### 通道职责分工
- **凯尔特纳**：管"日内波动边界"，负责精确入场
- **薛斯**：管"更大周期极端边界"，负责背景过滤

---

## 十一、通道信号体系

### 做多信号（强共振）
- 价格触及凯尔特纳下轨
- 薛斯长期通道走平或向上（非大角度下行）
- 价格同时处于薛斯短期通道下轨附近
- K线形态确认（长下影线 / 吞没阳线）
- 收盘价回到下轨之上

### 做空信号（强共振）
- 价格触及凯尔特纳上轨
- 薛斯长期通道走平或向下（非大角度上行）
- 价格同时处于薛斯短期通道上轨附近
- K线形态确认（长上影线 / 吞没阴线）

### 止盈目标
- 第一目标：凯尔特纳21中轨（EMA21）
- 第二目标：薛斯短期通道另一侧边界
- 第三目标：薛斯长期通道边界

### 止损
- 统一放在通道外轨外侧（凯尔特纳下轨下方 1×ATR）
